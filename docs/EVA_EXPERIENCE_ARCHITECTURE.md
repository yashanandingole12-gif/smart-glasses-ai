# EVA — Living Digital Phenomenon: Experience Architecture

## 1. Journey Architecture

EVA's interaction model is structured around **emotional states and gravity**, not static app screens.

```
       1. ARRIVAL ──► 2. AWAKENING ──► 3. CONVERSATION GRAVITY
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
        4. CREATION   5. RESEARCH   6. ORCHESTRATION
              │             │             │
              └─────────────┼─────────────┘
                            ▼
              7. SETTLING & MEMORY EMBEDDING
```

---

## 2. Experiential Stages

### 1. Arrival (The Quiet Void)
- **User Experience**: Opening the web portal or picking up the phone presents an unburdened, quiet universe.
- **Visuals**: Living dark canvas, a gentle glowing presence breathing slowly at the center, and a subtle command prompt: *"Speak or explore with EVA..."*
- **Aesthetic**: Zero clutter, zero telemetry walls, zero premature button grids.

### 2. Awakening (Voice or Gesture Wake)
- **User Experience**: The user says *"Hey EVA"* (via ESP32 microphone or phone) or types in the command field.
- **System Behavior**:
  1. The central presence shifts from *Awaiting* to *Listening*.
  2. Ambient light gathers around the command field.
  3. Harmonic audio waveform ripples in real-time.
  4. Audio chime acknowledges intent without blocking speech.

### 3. Conversation Gravity
- **User Experience**: Spoken inquiries appear as elegant typography streaming directly on the spatial field.
- **Visuals**: No generic chat bubbles. Responses unfold with natural typographic presence, highlighting key insights, synthesized citations, and direct actionable conclusions.

### 4. Creation (Atelier Space)
- **User Experience**: When asking EVA to code, draft, or synthesize concepts (e.g. *"Design a robotic arm controller"*):
  1. The spatial canvas expands smoothly.
  2. An interactive atelier surfaces syntax-highlighted code, structural diagrams, and execution controls.
  3. EVA maintains voice dialogue while the user interacts with the generated artifact.

### 5. Research (Orbital Constellation)
- **User Experience**: When asking academic or scientific questions (e.g. *"Research multimodal vision transformers"*):
  1. arXiv, Semantic Scholar, CrossRef, and OpenAlex results orbit as luminous nodes around the core query.
  2. Clicking a node unfolds paper abstracts, DOI links, author metadata, and a 2-sentence voice summary.

### 6. Device Ritual (ESP32 Glasses & TWS)
- **User Experience**: Bluetooth pairing is presented as a **recognition ritual** rather than a generic device list.
  1. ESP32 Glasses recognition: Visual alignment of audio stream (16kHz PCM), battery gauge, and BLE connection.
  2. TWS earbud routing: Audio automatically routes to earbuds for private listening or seamlessly falls back to phone speaker if disconnected.

### 7. Graceful Offline Resilience
- **User Experience**: When the cloud network disconnects, EVA deepens its velvet ambient tone.
- **Behavior**: Local deterministic math engine, cached memories, device telemetry, and hardware audio relay remain 100% active with no jarring red error alerts.

## 3. Web vs Mobile Topology

| Dimension | Web Command Realm | Android Portable Presence | Smart Glasses Sensory Field |
| :--- | :--- | :--- | :--- |
| **Role** | Deep Atelier & Observatory | Personal Ambient Companion | Perception & Audio Ingest |
| **Input** | Keyboard, Mic, File Drop | Voice ("Hey EVA"), Touch | Continuous PDM Microphone |
| **Output** | Visual Constellation, Audio, Code | Voice TTS, Haptic, Cards | BLE Audio Stream to Phone |
| **Density** | Expansive Spatial Canvas | Intimate & Minimal | Headless Physical Form |
